> Um exercício prático focado exclusivamente na engenharia da informação e semântica web, utilizando a versão mais recente da Linguagem de Marcação de Hipertexto.

## 🎯 Motivação e Propósito

No desenvolvimento web moderno, frameworks vêm e vão, mas o HTML permanece como a espinha dorsal de qualquer aplicação. O propósito deste repositório é demonstrar o domínio sobre a **estruturação lógica de páginas**.

Este projeto resolve o problema de criar interfaces acessíveis e "Search Engine Friendly". Ele aplica as tags corretas para cada tipo de conteúdo, diferenciando cabeçalhos de parágrafos, e dados tabulares de listas, assegurando que o navegador interprete corretamente a hierarquia da informação.

## 🛠️ Tecnologias Utilizadas

O projeto utiliza puramente a tecnologia nativa de estruturação da web:

* **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML):** Utilizado para:
    * **Semântica:** Tags estruturais (`<h1>` a `<h6>`, `<p>`, `<ul>`, `<ol>`).
    * **Interação:** Campos de formulário (`<input>`, `<textarea>`, `<select>`, `<button>`).
    * **Dados:** Organização de informações em tabelas (`<table>`, `<thead>`, `<tbody>`).
    * **Mídia:** Inserção de imagens (`<img>`).
